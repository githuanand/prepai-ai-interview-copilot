# 🚀 PrepAI – AI Interview Copilot

AI-powered interview preparation platform that helps candidates
analyze resumes, generate interview questions and evaluate answers.

## 🌐 Live Demo

👉 [Launch PrepAI](https://prepai-ai-interview-copilot-myfm3ib2hdyhruwjbbcv5v.streamlit.app/)


## ✨ Features

- 📄 Resume Analysis
- 🤖 AI Question Generation
- 📊 AI Answer Evaluation
- 📄 Interview Report Generation

## 🛠️ Tech Stack

- Python
- FastAPI
- Streamlit
- Groq AI
- PyMuPDF
- ReportLab

## 🔄 Workflow

Resume → Skills → Questions → Answer → AI Evaluation → Report

## 🚀 Deployment

Frontend: Streamlit Community Cloud  
Backend: Render
